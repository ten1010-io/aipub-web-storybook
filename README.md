# aipub-web-storybook

[aipub-web](https://github.com/ten1010-io/aipub-web) 의 Storybook 정적 빌드 호스팅 미러입니다.

- 공개 URL: https://ten1010-io.github.io/aipub-web-storybook/
- 빌드 산출물은 **`gh-pages`** 브랜치에 있으며, `aipub-web` 레포에서 `npm run deploy-storybook` 실행 시 force-push 로 자동 갱신됩니다.
- ⚠️ **이 레포에 직접 커밋하지 마세요.** 모든 변경은 `aipub-web` 의 컴포넌트·스토리에서 비롯되며, 재배포로만 반영됩니다.

> `aipub-web` 은 private repo 이고 org 가 free 플랜이라 Pages 를 직접 쓸 수 없어, 별도 public repo 로 분리해 호스팅합니다 (`aipub-frontend-storybook` 과 동일 패턴).
